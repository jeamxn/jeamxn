# Scroll-linked opening story

The opening follows the visitor's native scroll position rather than advancing
on a timer. Four scenes connect the person, the school-life problems behind
Dipull, work with colleagues at PFCT, and the collaborative ara workspace.
Facts and captions come from the existing reviewed public core. The four
representative works below the opening remain ara / Dipull / PFCT / KT SAT.

## Reference and original implementation

Reviewed the actual Apple AirPods Pro3 page, its built CSS and formatted main JS
on2026-10-15. Its audio-performance section uses a tall sticky-container, a
viewport-height sticky-element and anchor-based keyframes mapping scroll position
to media progress. The portfolio independently uses that native-scroll pattern
with original typography, portrait and already-reviewed product captures. No Apple
code, fonts, product photography or video are redistributed.

The visual system remains Wanted Sans / Geist, fog-white, ink, slate and cobalt.
One coordinated opening is the focus: large editorial copy and real images,
not a list of identical cards, fake dashboards or unrelated decorative objects.

## Interaction contract

- Native vertical scrolling: no wheel interception, scroll lock or artificial page snap
- Scroll-linked, reversible opacity and transform; stopping scroll stops the story
- A visible shortcut reaches representative work without watching every scene
- A static-reading switch, reduced-motion and short-view alternatives keep all text readable
- Initial server markup and hydration agree; no-JavaScript content remains available
- Only the active enhanced scene is interactive; hidden scene links cannot catch focus
- Existing archive86records,83other-work records/three-second rotation,
  product gallery15screens and public FAQ/PDF data are unchanged

## Preview boundary

The requested deliverable is a local company-Mac preview. Main and the live site
must not change without a separate instruction. Technical browser geometry and
screenshot generation are reported separately from the user's final visual review.
