# Noto Serif KR

Unmodified variable WOFF2 dynamic subsets supplied by Google Fonts CSS API.
Source CSS: https://fonts.googleapis.com/css2?family=Noto+Serif+KR:wght@500..600&display=swap
Upstream: https://github.com/google/fonts/tree/main/ofl/notoserifkr
Licensed under SIL Open Font License 1.1 (LICENSE.txt).
Font weights are exposed only for 500–600; original font data is unmodified.
`manifest.json` records original URLs, bytes, and SHA-256 for each file.
No requests to Google Fonts are made at runtime.
